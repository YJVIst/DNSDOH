# 多服务器、统一 DoH 域名（v0.3）

公共 DNS 只公开解析器服务器地址，用户实际查询的私有节点域名仍只在 DNSDOH 私有分区。公共 DNS 返回主控和已接入服务器的 IP；客户端直接与其中一台服务器建立 HTTPS，节点本机验证用户令牌并回答，不经过主控转发。

普通多条 A / AAAA 不保证选到最快服务器。当前部署没有开通 Cloudflare Load Balancing，未启用付费产品。不同递归 DNS / 客户端的排序、缓存和重试策略会影响连接结果。未来可集成供应商智能 DNS / 健康调度；现有 DNS-only 多地址不能宣称全球低延迟调度或 Anycast。

## 首次配置

首次登录会强制进入 DNS 供应商向导。支持 Cloudflare API Token / Global API Key、阿里云 AccessKey、腾讯云 DNSPod SecretId / SecretKey。应用验证凭据、分页读取账户权限范围内的域名，让管理员选择主域名及 DoH 主机标签，不自动选择账户中的其他业务域名。

权限需要列出域名、读取记录、添加和删除 DNS 记录。Cloudflare 建议 Zone Read + DNS Edit；AliDNS 需要 DescribeDomains / DescribeDomainRecords / AddDomainRecord / DeleteDomainRecord；DNSPod 需要 DescribeDomainList / DescribeRecordList / CreateRecord / DeleteRecord。权限不足会显示失败，修复凭据后可重试。

主控通过 DNS-01 申请受信任证书，配置本机 Nginx 并检查正确 SNI 下的 TLS 和就绪接口，之后才发布主控 A / AAAA。不得覆盖已有的外部业务记录；自动删除前再次核对托管记录 ID、类型和值。

## 添加服务器

默认填写公网 IP、SSH 端口、用户名和密码 / 私钥，点击检测 SSH 指纹。首次连接应通过服务器控制台核对指纹；已保存指纹匹配可复用。重装系统改变指纹时会显示旧 / 新指纹，重新确认前不得发送登录凭据；实际建立部署连接时再次检查，防止检测后被替换。

SSH 密码、私钥和私钥密码只在当前后台任务内存中使用，不落库、不写入安装文件或日志。支持 root，或可执行免密 sudo 的用户。主控重启后中断任务显示失败，可重新提交。

可选择「一次性安装命令」下载文本，在服务器 root 终端运行。接入票据随机、15 分钟有效、只使用一次；安装脚本哈希固定，下载二进制按 manifest SHA-256 校验。票据通过标准输入交给接入进程；节点在本机生成 Ed25519 私钥，仅向主控登记公钥。

安装目录 `/mnt/youlin-data/dnsdoh-node`。程序使用非特权用户运行，默认选择空闲的 18081–18110 回环端口。root 维护任务只负责证书与 Nginx 配置。已有不属于 DNSDOH 的 HTTPS 配置不会被无条件覆盖；程序失败时保留明确错误，而不是停止其他业务。

## Linux 平台

发布 agent 为 x86_64 musl 静态二进制。安装器包含 Debian / Ubuntu apt、Rocky / Alma / RHEL / Fedora / Amazon dnf 或 yum、SUSE zypper、Arch pacman，以及 Alpine apk 的检测与安装路径。systemd 使用 service + timer；Alpine 使用 OpenRC + cron。ARM64 尚无发布产物。

兼容性证据分两类：真实 Debian 13 服务器进行完整 SSH 安装验收；Alpine 3.23、Ubuntu 24.04、Debian 12、Rocky 9 使用官方根文件系统验证静态程序可执行及平台计划。后者不代表这些发行版的完整 systemd / OpenRC / SELinux 安装已逐一实机验收。

## 连接安全

配置同步和根权限维护均使用 HTTPS，严格验证服务端证书；请求用 Ed25519 签名覆盖节点 ID、时间戳、随机 nonce 和请求体哈希。控制接口使用独立签名上下文，拒绝跨接口重放。主控存储和验证 nonce；只接受启用节点。节点可固定主控 IP，但保留原主机名的 SNI / 证书验证，不使用跳过证书检查。

公共 DNS 的解析器地址是公开信息；HTTPS 内的私有查询和令牌不会因此变成公开 DNS 记录。DNS 污染可以影响可用性，但在证书校验正常时不能直接冒充解析器读取查询。私有分区查询失败不会递归回退到公共 DNS。

为支持一个统一域名，每个可信服务器获得该域名的证书及私钥，传输使用签名认证的 HTTPS，落盘权限 0600。主控中的供应商密钥、ACME 账户及证书私钥使用 AES-256-GCM 加密。节点拥有完整授权配置及统一域名证书，因此只能接入可信管理员控制的主机。

## 同步、健康与删除

配置每 3 秒同步，15 秒租约到期停止解析；节点重启后必须先同步。停用 / 删除节点会撤销其身份，后续同步被拒绝。DNS 管理约每 10 秒协调：新节点须有新域名绑定、近期心跳、真实 TLS / 就绪检查通过，才发布公共记录。连续健康检查失败会撤下记录，恢复可重新加入。

Cloudflare 记录 TTL 60 秒，AliDNS / DNSPod 当前采用 600 秒。递归缓存、客户端缓存可能延迟撤下效果，不能将记录删除视为即时断开连接。供应商 API 暂不可用时保留待删除记录账本并重试，不会遗失清理任务。

用户令牌只控制新的 DNS 查询，不撤销已获取 IP、已建立代理连接或第三方转发的地址。主控仍负责配置和租约，不能将节点直连解释为主控失效后无限期可用。

## 域名修复与更换

后台显示供应商域名状态、公共 NS 可解析性、证书到期时间和配置错误。点击修复会重新检查并重试失败证书任务。监测不保证覆盖所有注册商、DNSSEC 或区域网络故障。

更换时选择新域名 / 标签：先申请证书和配置主控，激活新域名，再由节点维护任务自动获取绑定并添加新域名记录。旧域名默认保留 7 天，之后自动清理本项目记录和节点 Nginx 绑定。管理员仍须通知用户修改 DoH URL；原用户令牌不变。旧域名已彻底失效时无法依靠旧 URL 自动通知客户端。

DoH 域名和管理后台域名分开。此流程更换 DoH 域名；管理后台 URL、管理证书的迁移仍需运维配置。应避免将唯一管理入口的存续完全依赖于需要替换的 DoH 域名。
